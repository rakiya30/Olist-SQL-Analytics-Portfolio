# Olist SQL Data Analytics Portfolio

## Project Overview

This project demonstrates an end-to-end data analytics workflow using the Olist Brazilian E-commerce dataset.

The goal is to analyse customer behaviour, orders, products, payments, sellers and delivery performance using SQL Server, Excel and Power BI.
