# Olist E-Commerce Power BI Dashboard

## Project Overview

This project presents an interactive Power BI dashboard built using the Brazilian Olist e-commerce dataset.

The dashboard transforms the cleaned and analysed data into clear business insights around customers, orders, delivery performance and order status.

## Tools Used

- Power BI
- SQL Server
- DAX
- Power Query
- Data Visualisation
- Data Analysis
- Business Intelligence

## Dashboard Overview

The dashboard provides an overview of Olist's e-commerce performance through key performance indicators and visualisations.

### Key Metrics

- **Total Customers:** 99K
- **Total Orders:** 99K
- **Delivered Orders:** 96K
- **Delivery Rate:** 97.0%
- **Average Delivery Time:** 12 days

### Visualisations

The dashboard includes:

- Orders Over Time
- Order Status Distribution
- Customer State Distribution
- Key performance indicator cards

## Key Business Questions

The dashboard was designed to explore:

1. How have order volumes changed over time?
2. Which customer states generate the most orders?
3. What is the distribution of order statuses?
4. What percentage of orders are successfully delivered?
5. What is the average delivery time?

## Key Insights

The analysis highlights overall order performance, customer distribution across Brazilian states and delivery efficiency.

The dashboard allows users to quickly identify trends and understand the overall performance of the Olist e-commerce operation.
