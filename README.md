# 🛍️ Olist E-commerce SQL Analytics Portfolio

## 📌 Project Overview

This project analyses the Brazilian Olist e-commerce dataset using SQL Server.

The objective is to answer business questions using SQL while demonstrating data analysis, problem-solving, and business thinking.

This project forms part of my Data Analytics portfolio.

# Business Questions Solved

- Which states have the most customers?
- Which cities have more than 1,000 customers?
- How many unique cities do we have customers in?
- How many customers are located in RJ?
- Show all customers who live in SP or RJ.
- Show customers whose city starts with "S".
- Show customers whose city contains "rio".

---

# Key Business Insights

- São Paulo (SP) has the largest customer base.
- Customer distribution varies significantly across states.
- SQL filtering can identify customers by location and text patterns.
- Distinct counts help measure geographical reach.
